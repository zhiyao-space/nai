NovelAI 图像生成
画面描述 (提示词) 0

用文字描述想画的内容：人物、动作、服装、背景、画风都可以写。写得越具体，画面越贴近预期。

自动画质词：开启后自动附加「very aesthetic, masterpiece」等关键词，整体更精致。自动排除瑕疵：生成时自动排除模糊、低质量、水印等常见毛病，不用手写。

排除内容 (负向提示词) 0

写不想出现在画面里的东西，例如：两个人、文字、水印、模糊。开启「自动排除瑕疵」时留空即可，会自动填入常用排除项。

氛围转移 (Vibe Transfer)

上传参考图当「氛围板」：生成时 AI 会参考它的画风、色调和构图。每张图可单独调「信息提取」(从图里提取多少细节, 默认 1.00) 和「参考强度」(对画面的影响多大, 默认 0.60)。点缩略图可替换这张氛围图；氛围图自动按比例缩小到最长边 1024 后提交。V4 / V4.5 最多 5 张, V3 仅 1 张; 与图生图 / 局部重绘可叠加使用。仅 NovelAI 官方格式支持。

点这里选图 · 拖拽 · Ctrl+V 粘贴 (最多 5 张)

多角色设定 (角色提示词)

给每个角色单独写外貌描述，还能指定站位，适合画多人图。仅 V4 / V4.5 模型支持；V3 模型会自动合并进主描述。「指定站位」= 按每个角色的位置百分比安排站位；「按顺序画」= 角色按列表顺序出现。

AI 设置

凭空画：纯文字从零生成。照图改：上传原图让 AI 参考着改。局部重绘：在原图上涂抹一块区域，只重画那一块，其余保持原样。

点这里选图、把图片拖进来、或直接 Ctrl+V 粘贴截图。加载后画面尺寸会自动同步为原图尺寸。

点这里选图 · 拖拽 · Ctrl+V 粘贴

0 = 几乎不动，1 = 完全重画。想在原图上小改就调低 (0.4~0.6)，想大变样就调高 (0.7 以上)。

往原图里掺多少随机干扰，越大变化越自由。一般 0~0.3，不需要就保持 0。

用手指/鼠标在图上涂抹想重画的部分，紫色区域就是重画范围，其余保持原样。涂错了切到「擦除」擦掉即可。

模型列表自动从你配置的中转站拉取，「图像模型」分组置顶。列表里找不到的模型，去右上角「设置」用「自定义模型名」填写，填写后优先生效。

竖图适合人物立绘、手机壁纸；横图适合风景场景；方图适合头像。开启「高清大图」分辨率更大、细节更多，消耗也更高。

x

AI 反复打磨画面的次数：越高越精细，也越慢、越耗资源。默认 28 已经很均衡。

AI 有多严格地服从你的描述。太高会僵硬、颜色过艳；太低会自由发挥跑偏。常用 4~7。

生成画面的算法，不同算法笔触手感不同。不确定就保持默认的 Euler。

控制生成过程的收敛节奏，一般保持 karras 就好，对画面影响不大。

调高后构图和内容更随机多变，适合抽卡找灵感；保持 0 则完全按参数稳定出图。

修正「听话程度」开太高导致的颜色过艳、对比过强，0~0.5 之间微调即可。

相同编号 + 相同参数 = 完全相同的图。留空则每次随机；骰子按钮一键随机，想「换个构图再画一张」就用它。

一次生成几张图，越多越慢、消耗越多。抽卡建议一次 2~4 张挑最好的。

中转站 API 设置

填写你的 API 中转站网址，例如 https://api.example.com。会自动补全 https:// 前缀。

中转站给你的密钥，一般以 sk- 或 pst- 开头。只保存在你手机浏览器里，不会上传到别处。

看你用的中转站支持哪种：转发 NovelAI 官方接口的选「NovelAI 官方格式」；给 /v1/images/generations 这类通用接口的选「OpenAI 兼容格式」。空悲切等提供 NovelAI 原生格式调用的中转站，直接用默认的「NovelAI 官方格式」即可，无需改动。

中转站给了特殊接口地址时才填，例如 /api/draw。通常留空就行。

保存设置后自动从中转站拉取模型列表。模型多时用「搜索模型」输入关键词过滤，或点「只看绘画模型」自动识别筛选出绘画类模型；列表里没有的模型，直接在下面「自定义模型名」填模型 ID，填了以后优先生效。

「中→英」翻译按钮使用的聊天模型，与绘画模型走同一个中转站。建议选便宜快速的模型，如 gpt-4o-mini、gemini-2.5-flash。留空则翻译按钮提示先去设置。
