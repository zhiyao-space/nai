# 需求文档：中转站模型源改造与 Anlas 移除

Feature Name: relay-model-source
Updated: 2026-11-08

## 引言

模型选择不再内置模板清单，改为从已配置的中转站动态拉取绘画模型（`/v1/models`，两种接口格式通用）；同时移除顶部 Anlas 参考估算标识及其全部联动逻辑。

## 决策点 (默认决策，需求明确)

1. 模型列表拉取地址统一为 `{Base URL}/v1/models`（new-api/one-api 类中转站无论下游格式均提供该端点）。
2. 拉取结果按图像模型启发式分组（id 含 nai/diffusion/dall-e/flux/sd/seedream/kolors/cogview/gpt-image 等），「图像模型」组置顶，其余进「全部模型」组；无匹配时平铺单组。
3. 「自定义模型名」输入保留，填写后仍优先生效。
4. Anlas 估算整体移除（顶栏标识、估算函数、全部 updateAnlas 联动、文案），恢复须接官方精确计费公式。

## 需求

### 需求 1：中转站模型动态拉取

**用户故事**：作为中转站用户，我希望模型下拉框直接反映中转站实际可用的绘画模型。

#### 验收标准

1. WHEN 设置保存成功或应用启动且已配置中转站地址，系统 SHALL 自动请求 `{Base URL}/v1/models` 并以结果填充左面板与设置弹窗的模型下拉框。
2. WHEN 下拉框渲染且结果中存在图像模型匹配项，系统 SHALL 以「图像模型」分组置顶，其余模型归入「全部模型」分组。
3. IF 启动时的自动拉取失败，系统 SHALL 静默降级为显示当前模型，并提供设置弹窗内的「重新拉取模型列表」按钮手动重试（失败时 toast 提示）。
4. WHEN 用户在「自定义模型名」填写模型 ID，系统 SHALL 以其作为生效模型并在下拉框显示「自定义中转站模型: xxx」。
5. WHEN 历史记录复用参数且模型 ID 存在于拉取列表或已知 NovelAI 命名，系统 SHALL 直接选用；否则进入自定义模型名通道。

### 需求 2：Anlas 移除

**用户故事**：作为用户，我希望去掉顶栏无实际作用的 Anlas 估算标识。

#### 验收标准

1. 系统 SHALL 从顶栏移除 Anlas 标识元素及其样式。
2. 系统 SHALL 移除估算函数与全部调用点，生成按钮提示文案同步去除 Anlas 字样。
3. 需求 1 与需求 2 的变更 SHALL 遵循既有结构 (js/api.js 载荷与工具层 / js/app.js UI 层 / index.html / css)。
